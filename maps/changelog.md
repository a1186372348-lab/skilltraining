# 变更与决策记录（maps/changelog.md）

> 文档类型：长期治理文档——决策记录 + 项目变更时间线（二合一）
> 负责范围：①已锁定或已拍板的产品与工程决策（D 编号）全文，为唯一事实源；②随时间变化的项目历史：功能交付、契约变化、决策锁定、文档治理变动
> 事实来源：产品负责人确认记录（D 编号决策 2026-10-07 自 `Prd.md` 第 0 章迁出，原文未改动）、Git 提交历史、`task/` 任务状态
> 更新触发：新决策拍板、旧决策被取代或修订、每次合并到 main、每次发布、每次文档治理结构变化——必须在同一变更中更新本文件，否则该改动不算完成

## 使用约定

**决策部分：**

- D 编号只增不复用；被取代的决策保留原文，并在条目标注取代关系（"已被 Dx 取代"），保证决策演变可追溯。
- 其他文档（`Prd.md` 正文、`task/` 任务、代码注释）只引用 D 编号，决策全文以本文件为唯一事实源。
- 新增决策必须写明日期与拍板人；修订旧决策时以新条目取代，不原地改写历史。

**变更时间线部分：**

- 倒序排列（最新在上），每条包含：日期、类型（`feat / fix / docs / decision / chore`）、一句话内容、关联引用（T 编号 / D 编号 / 提交哈希）。
- 决策在时间线中只记录编号与标题，全文见上方「决策记录」，不复制。
- 只追加，不改写历史条目；记录错误时新增一条更正记录。
- 本文件既面向产品历史回顾，也面向 AI 快速了解项目演进，条目须一句话可读。

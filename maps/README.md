# 当前事实地图（maps/）

> 文档类型：项目事实地图入口
> 负责范围：已实现并经代码/配置验证的**当前事实**——模块地图、接口清单、数据结构、操作手册
> 更新触发：代码行为、API、数据库、目录或页面行为变化时，必须在同一变更中更新对应地图

## 目录职责

| 目录 | 负责内容 | 不负责内容 |
|---|---|---|
| `maps/` | 已实现的当前事实、模块地图、操作手册 | 未实现目标、任务正文、真实用户数据与密钥 |
| `docs/` | 计划方案、评审、决策前材料 | 当前实现的事实、长期操作手册 |
| `task/` | 可执行任务、临时执行方案、验收证据 | 通用规范、未来方案全文 |

## 内容准入

允许：

- 已实现模块的职责、公开入口和调用关系（`modules.md`）
- 已实现 API 的请求、响应、错误和页面消费者（`api.md`）
- 数据库表、迁移、文件存储的当前结构（`data.md`）
- 架构、分层、依赖和数据流的当前状态（`architecture.md`）
- 安装、启动、配置和故障诊断（`operations.md`）

禁止：

- 未实现或部分实现的目标方案（进入 `docs/`）
- 阶段任务、执行计划正文（进入 `task/`）
- 真实用户数据、数据库内容、密钥

## 地图文档约定

- 每份地图顶部必须声明：文档类型、负责范围、事实来源、更新触发条件。
- 只记录当前实现能够证明的事实；与代码冲突时以代码为准，并在同一变更中修正地图。
- 过期内容应修订、合并或删除，不得以追加历史段落代替当前事实。
- 不复制源代码全文；私有函数只在影响跨模块行为时记录。

## 读取规则

1. 先在本入口确定目标文档，再用关键词搜索定位章节，不默认全文加载。
2. 只有维护、审计或用户明确要求时，才允许完整读取目标文档。

# T15：我的页面（P6 /settings）

| 项目 | 内容 |
|---|---|
| 状态 | IN_PROGRESS（已派发 K2.8 子代理） |
| 依赖 | T03（登录/注销）、T04（画像接口） |
| 事实来源 | `Prd.md` 2.3 页面 P6；2026-10-04 产品负责人反馈（点击「我的」404 阻断测试） |

## 目标

补齐侧边栏「我的」入口：账号信息、初始画像查看与编辑、退出登录。

## 范围外

训练偏好等高级设置（占位卡即可）；修改密码（无密码体系）。

## 交付

1. `app/settings/` 页面（复用侧边栏外壳模式）：
   - 账号信息卡：当前登录邮箱（GET /api/auth/session；开发态身份显示 dev 标识）；
   - 初始画像卡：查看 + 编辑——复用 `app/onboarding/profile-form.tsx` 的字段结构（预填 GET /api/profile，保存走 PUT /api/profile，幂等）；
   - 基础设置占位卡（虚态，标注后续版本）；
   - 退出登录按钮（POST /api/auth/logout → 跳转 /login）。
2. 测试：视图装配纯函数（画像预填映射、dev/真实身份分支）；路由级验证可沿用既有模式。

## 失败与回滚

画像保存失败可重试且不丢当前编辑内容；全部为新文件，回滚即删除。

## 验收条件与完成证据

- `/settings` 200，四卡齐备；画像编辑保存后刷新数据一致；退出登录后回 /login
- `npm run typecheck && npm run test && npm run lint && npm run build` 全绿

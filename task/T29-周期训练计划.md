# T29 周期训练计划（F5）+ P3 公共 Schema 前置

状态：PENDING（2026-10-08 立项，决策见 maps/changelog.md D29/D32/D33②/D34）

## 目标

交付「周期训练计划」：每周一生成「本周主攻维度」计划——规则引擎取画像最低分维度（同分按固定顺序），理由文案模板化、不用 AI（架构蓝图 §4 选型决策）；日常选题优先匹配主攻维度（BR-V2-1 优先级链中的「计划层」）；周日生成周回顾（完成天数、主攻维度有效分变化）；用户可拒绝，拒绝后本周选题不再命中该维度、不再重复推荐（BR-V2-2 / D33②）。

本任务同时承担 P3 公共前置：`TrainingSession` 新增 `sourceType`（daily/extra/baseline/plan/pack/retest）+ `sourceId`（可空）迁移与历史数据回填（kind=baseline→baseline、isExtra=true→extra、其余→daily），T30（训练包）/T31（复测）直接复用，不再各自迁移。

## 范围外

- 专项训练包（归 T30）：含 BR-V2-2 后半句「系统推荐/生成该维度训练包」的入口；
- 成长阶段与复测（归 T31）：选题链中的「复测层」本任务不实现，仅留接入位置；
- 首页战役地图整体改造（阶段路径等）：本任务只做周计划卡在首页的接入与悬挂呈现，首页布局以组合原型 docs/v2/v2-prototype-final.html 为准、在 P3 各任务间协同；
- 定时调度器/cron：计划与周回顾均为「首次访问时懒生成」（蓝图 §2.4），不引入后台任务；
- AI 生成计划理由（V3 再议，蓝图 §4）；
- `score-notifications` 排除规则调整（包题/复测题通知归 T30/T31 确认，蓝图 §3.1）。

## 受影响模块/数据/接口

- **prisma/schema.prisma（两次迁移，可合并评审）**：
  - `TrainingSession` 新增枚举字段 `sourceType: TrainingSessionSource`（daily/extra/baseline/plan/pack/retest，默认 daily 兜底）+ `sourceId String? @db.Uuid`（计划/包 id，可空）；
  - 新表 `training_plans`：`id, userId, weekStartDate(@db.Date，周一), focusDimension, startScore, targetScore, status(active/rejected/completed), reason, createdAt`（蓝图 §3.3 草案）；`@@unique([userId, weekStartDate])` 保证懒生成幂等（并发首访不双写），另加 `@@index([userId, status])`；
- **新增 `server/modules/planning/`**（五件套）：`service.ts`（周一懒生成/拒绝/撤销/进度聚合/周回顾懒生成与归档）、`repository.ts`、`schemas.ts`（zod）、`errors.ts`、`index.ts`（公开入口）；
- **修改 `server/modules/selection/`**：选题入口前置优先级链，本任务接入「计划层」——本周计划 active 且今日未练计划题时，在主攻维度内选题（复用引擎同维度匹配），命中即返回 `sourceType="plan"` + 模板理由；未命中（该维度无可用未练题等）落现有自适应分支。包层（T30，插于计划层之前）与复测层（T31，插于计划层之后）仅留注释级接入点，不提前实现；`SelectionOutcome` 扩展 `sourceType` 与理由文案字段（R5）；
- **修改 `server/modules/training/service.ts`**：会话创建携带 `sourceType`/`sourceId`（今日选题按选题结果落 plan/daily；加练落 extra）；`server/modules/baseline/` 会话创建透传 baseline；
- **新增 API `app/api/plans/`**：`current/route.ts`（GET：懒生成 + 返回本周计划、理由、进度聚合）、`reject/route.ts`（POST：body 经 zod 判别 `action: "reject" | "unreject"`，幂等）、`review/route.ts`（GET：周回顾，周日及之后首访懒生成并将上周计划归档 completed）；未登录 401；
- **UI**：`app/training/` 大厅新增周计划条/计划详情（屏 3：主攻卡当前分→目标分+理由前置、周一至周五排期三态、拒绝/撤销交互、周回顾卡）；首页（`app/page.tsx` / `app/_dashboard/`）新增悬挂计划卡（屏 1 样式，只接入悬挂卡，不动整体布局）；新增前端 view-model 纯函数承载展示逻辑。

## 失败与回滚

- **迁移可回滚**：均为 additive 变更（新列 + 新表）；回滚方式 = 新建回滚迁移（DROP `training_plans`、DROP `sourceType`/`sourceId` 列与枚举）或 revert 迁移目录后重建；执行迁移前必须先备份本地开发库（pg_dump），严禁在未备份库上直接 migrate；
- **数据保护**：回填只写新列，绝不修改 isExtra、question.kind 等既有事实列；回填 SQL 幂等可重跑；回填错误会污染统计（蓝图 R2），验收前必须完成分组计数抽查；
- **代码回滚**：planning 模块、`app/api/plans/`、UI 卡片均为新增，摘除挂载/路由即回滚；selection 计划层未命中时自动落现有自适应分支，摘除计划层接入即恢复原选题行为，不影响 V1 闭环；
- 接口或计划数据异常时前端降级为不展示计划卡，绝不影响今日训练主流程渲染。

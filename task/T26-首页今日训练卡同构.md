# T26 首页今日训练卡与大厅当前训练卡同构

状态：IN_PROGRESS（2026-10-07 立项，决策见 maps/changelog.md D28——产品负责人要求首页「今日训练」卡片与产品训练大厅「当前训练」卡展示完全一致，同样三态：未完成/待继续/已完成）

## 目标

首页左列的「今日任务」卡替换为与大厅完全一致的「当前训练」三态卡：同一共享组件渲染、同一服务端判定数据源（单一事实源），两处永不漂移。

## 范围外

- 大厅页、训练工作台、反馈页、历史详情的任何变更；
- 三态卡的文案与视觉调整（目标是与大厅一致，不是 redesign）；
- 首页诊断卡、能力总览卡、问候行与统计条；
- 基线测评流程（仅保留既有门禁行为：开始按钮经 today 接口，kind=baseline 跳 /baseline）。

## 事实来源与前置依赖

- 决策：maps/changelog.md D28（含五条落地口径）；
- 三态判定单一事实源：`server/modules/training/hub-view.ts` 的 `resolveCurrentCard`（T25）；
- 三态卡现有实现：`app/training/hub-flow.tsx` 的 CurrentCard / InProgressCard / NotStartedCard / CompletedCard + Badge（含 onStartToday（fetchTodaySession + 基线门禁 + 跳 /training/session/[id]）与 onStartExtra（startExtraSession 拿 sessionId 直达）两个动作，当前由 TrainingHubFlow 持有 pending/error 状态）；
- 被替换对象：`app/_dashboard/home-dashboard.tsx` 的 TaskCard（今日任务预览卡：caseTitle/能力标签/训练重点/为什么是它/今日问题 + 单 CTA）；其数据来自 `server/modules/dashboard/`（contract.ts 的 TodayTaskCardData、assemble.ts 的 buildTodayTaskCard/buildWhyText、service.ts 装配）；
- 首页侧栏「今日状态」文案现由 `sessionStateLabel(view.todayTask…)`（app/_dashboard/view-model.ts）供给；大厅同职能函数为 `sidebarStageText(current)`（app/training/view-model.ts）；
- 容错约定（T08）：单卡数据为 null 渲染空态虚线卡，不拖垮整页。

## 受影响模块/数据/接口

- 新增共享组件 `app/training/current-training-card.tsx`：从 hub-flow 抽出三态卡与 Badge，**自持全部动作逻辑**（开始今日训练/再练一题的 pending、行内错误、router 跳转；查看结果 Link），props 仅 `current: HubCurrentCard`；hub-flow.tsx 改为渲染该共享组件（删除本地三卡实现）；

- `server/modules/dashboard/`：service 装配新增 `currentTraining`（调 getCurrentTrainingCard，按 T08 约定失败容错为 null）；contract.ts 的 DashboardView 新增 `currentTraining: HubCurrentCard | null`；移除 TodayTaskCardData / buildTodayTaskCard / buildWhyText——**动手前必须 grep 确认无其他消费方**，有则在回报中说明并保留；
- `app/_dashboard/home-dashboard.tsx`：TaskCard 删除，原位渲染共享三态卡（currentTraining 为 null 时渲染空态虚线卡）；stageText 改用 sidebarStageText（view-model.ts 的 ctaLabel / sessionStateLabel 若因此无消费方则删除，测试同步）；

# T33 题库扩容（日常 30~50 + 基线 16 + Question domain 字段）

状态：PENDING（2026-10-08 立项；功能包 F1，排期 P0，内容任务；决策见 maps/changelog.md D29~D34）

## 目标

- **题库供弹**：新增基线题 16 道（`kind: baseline`，八维各 2 道候选，难度基础层）+ 日常题按需新增（预估 36~45 道，第二、三批各 15~20 道并以覆盖矩阵缺口为准），使日常题每维度 ≥6 道（D35 上调：组包 5 道 + 复测预留 1 道）、难度三层均有分布、领域不集中于单一产品（BR-V2-8），为 T30 组包、T31 复测供弹药；基线题在第一批交付（T27 硬依赖，D30）。
- **Schema 与管线扩展**：Question `+domain`（领域标签）迁移与老题回填；`question-schema.ts` 增加 domain 校验；validate/import 管线输出覆盖矩阵分布报告（按维度/难度/领域），domain 数据供 T29 计划维度匹配复用。
- **标准答案同步生产**：每批题目入库时同步产出每题 1~2 份标准参考答案 YAML（AI 起草 + 人工评审修订，D31），入 Git 管理，供 T28 评测集使用。
- **三批生产评审**（D33③）：每批节奏固定为 AI 起草 → 初审 → 产品负责人定稿 → 校验导入。

## 范围外

- 任何训练 / 选题 / 评分 / 基线流程代码改动（归 T27~T31）；本任务 domain 只落库与统计，运行时代码不读取（T29 起才消费）。
- 评测集工具链：回归执行、一致性对比、人工评分基准与期望分数带契约（归 T28）；本任务只定义标准答案最小 YAML 契约并产出内容。
- 难度标签枚举改动：三层沿用现有 `基础/中等/挑战`（PRD 措辞「进阶」对应现有「中等」标签），不改 `DIFFICULTY_LABELS` 与映射。
- V1 已有 B1/B2 综合基线题（挑战难度）的取舍与共存策略（归 T27）。
- domain 领域词表硬编码进 zod 枚举：词表按本文件约定管理、评审统一口径，随题库演进不改 schema。

- `server/modules/content/import-questions.ts`：upsert 映射增加 domain。
- `scripts/validate-content.ts`：追加覆盖矩阵报告输出 + `content/eval/` 标准答案校验（契约失败才 exit 1；覆盖缺口只报告不拦截，达标核对属评审动作）。
- `scripts/import-content.ts`：导入摘要后输出同一覆盖矩阵报告。
- `content/questions/draft/`：新增 46~56 个 YAML（沿用 draft/ 目录惯例，上架由 status 字段控制）；内容 id 建议基线 B3~B18、日常 Q13 起顺延（评审可调整）；老 14 题补 domain。

**题目生产规格（在 T13 契约之上追加）**

- 基线题 16 道：`kind: baseline`、难度 `基础`；「每题主测 1 个维度」（BR-V2-6）的主测维度 = `ability_tags` 首标签（生产约定；Rubric 仍须覆盖全部 2~4 个标签，schema 强制）；八维各 2 道按首标签口径统计。
- 日常题 30~40 道：`kind` 缺省（daily）；难度三层均布；领域词表建议：内容/社交、电商、本地生活、出行、工具/效率、办公协同、教育、金融、健康/运动（以现有 12 题为种子，评审统一口径、允许增补，禁止一题造一词）。
- 每题同步产出标准答案 1~2 份：AI 起草 + 人工评审修订； answer 为完整可参考作答，不泄露进题库运行时字段。

## 失败与回滚

- **迁移回滚**：仅新增可空列，回滚 = 新建反向迁移 `DROP COLUMN domain` + git revert 代码与 YAML 的 domain 字段；V1 运行时代码不读 domain，回滚不影响线上行为。DROP COLUMN 会丢失已回填数据，回滚前先 `pg_dump -t questions` 备份该表。
- **内容回滚**：题目与标准答案全部为新增文件，git revert 即回滚内容源；库内已导入行不会被 import 删除（只 upsert 不删除），下架走 `status: archived` 后重跑导入；禁止物理删除已被 TrainingSession 外键引用的题。
- **导入保护**：整批单事务、任一题校验失败整批取消不写库（T02 既有约定）；内容 id 一旦入库不得改名（UUID v5 由 id 派生，改 id = 产生新题、旧题成孤儿）。
- **数据保护**：`content:import` 默认连开发库，批次导入前确认 `DATABASE_URL` 指向；集成测试只跑隔离库 skilltraining_test（T14），不得对开发库/生产库执行测试。
- **标准答案安全**：只入 Git 的 `content/eval/`，不进 questions 表、不下发前端；泄露口径与 rubric 同级管理。

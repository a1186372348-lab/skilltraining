# T16：能力画像 3D 力导向网络图（D20）

| 项目 | 内容 |
|---|---|
| 状态 | IN_PROGRESS（已派发 K2.8 子代理） |
| 依赖 | T06（画像数据）、T09（画像页）；**已批准安装 three + react-force-graph-3d（仅本任务可动 package.json）** |
| 事实来源 | `Prd.md` D20、2.3 页面 P2（2026-10-04 产品负责人决策） |

## 目标

能力画像主视图从条形列表升级为知识空间中的 3D 力导向网络图：8 维节点全连接，粗细示强弱，可拖动/旋转/缩放，点击节点看评估依据。

## 范围外

二级维度节点、边按语义相关性稀疏化（V1 全连接）；动画特效。

## 交付

1. 服务端：扩展 `GET /api/profile/ability` 每维度负载——新增 `latestDiagnosis`（该维度最近一次评分的诊断原文 + 日期）与 `recentScores`（近 N 次有效分序列，供趋势）；TDD 先行。
2. `app/profile/` 新增网络视图（默认）与现有列表视图的 Tab 切换：
   - 节点 = 8 维度：分数决定大小与颜色（高分大且实色，低分小且淡），未观测半透明灰态；
   - 连线 = 全连接（28 条），粗细 = 两节点分数的**短板（较低分）**归一化映射；任一端未观测则该边为最细虚态；
   - 交互：拖动/旋转/缩放（库自带）；点击节点弹窗——评估依据（最近评分 + AI 诊断原文 + 日期）、观察次数与趋势（迷你走势）、提示依赖特征、下一步训练方向；
   - 技术：react-force-graph-3d 客户端渲染（dynamic import + ssr:false），深色「知识空间」底衬可与浅色列表视图共存。
3. 节点/连线映射为纯函数（短板规则、归一化、灰态）并 vitest 覆盖；组件本体经 build 验证。

## 失败与回滚

3D 库加载失败降级为列表视图并提示；网络图不改变任何数据结构。

## 验收条件与完成证据

- `/profile` 默认展示 3D 网络图，8 节点全连接、粗细符合短板规则、弹窗四要素齐全；可切回列表视图
- 全未知用户：全部节点半透明灰态、全部连线最细虚态，不报错
- `npm run typecheck && npm run test && npm run lint && npm run build` 全绿

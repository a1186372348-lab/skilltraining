# T27 基线测评升级（八维全覆盖）

状态：PENDING（V2 功能包 F7，排期 P2；决策见 maps/changelog.md D29 / D30 / D34）

## 目标

基线测评从 V1 的 2 道综合题升级为八维全覆盖测评（BR-V2-6 / D30）：

- 8 题起步，每题主测 1 个能力维度（kind=baseline），题序 = 八维固定顺序；
- 评分 confidence 低于阈值（初定 70，T28 回归集标定，可配置）的维度自动加深 1 题，每维至多加深 1 题、总题数上限 12；
- 支持分段完成（至少 2 次）、断点续测——复用现有 `{userId, questionId}` 幂等会话机制，不引入新状态机；
- 全部完成后写 `baselineCompletedAt`、八维画像一次点亮，新用户跳过探索期直接进入强化期（八维均有观测后现有 selection 引擎自然进入强化期，selection 不改代码、只做回归验证）。

## 范围外

- 基线题库内容生产（基线 16 题、每维 2 道候选——归 T33 第一批，BR-V2-8）；
- 评分 confidence 的 prompt 产出、阈值标定与回归集门禁（归 T28）；本任务只负责 confidence 字段落库与消费；
- 周计划 / 训练包 / 成长阶段与复测（归 T29~T31）；
- selection 引擎选题逻辑改动（本任务仅验证八维有观测后自然进入强化期）；
- 首页战役地图改版（另立 V2 首页任务；本任务仅保证现有基线门禁行为不回归）。

## 失败与回滚

- **迁移回滚**：confidence 为可空新列、非破坏性变更；回滚 = 反向迁移（`ALTER TABLE scores DROP COLUMN confidence`）。顺序要求：先回滚读取该字段的代码，再回滚迁移。
- **数据保护**：老 Score 行 confidence 一律保持 NULL，不做任何回填或改写；baselineCompletedAt 保持守卫式 updateMany 并发语义，重写不得改变；基线会话仍 isExtra=true 落库，历史会话归属与画像计入口径不变；训练历史 / 通知等按 `question.kind="baseline"` 过滤的既有逻辑（T24、F2 修补项）题量变化后行为须回归确认。
- **降级开关**：加深判定异常时无需回滚部署——阈值配置临时调至 0 即等效关闭加深、回到固定 8 题。
- **代码回滚**：全部改动在功能分支上进行，前端保留 required / total / doneCount 兼容语义，摘除新流程挂载点即可整体回退。

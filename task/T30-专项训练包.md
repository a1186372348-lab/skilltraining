# T30 专项训练包（F4）

状态：PENDING（2026-10-08 立项；V2 功能包 F4，P3 排期第 2 个，范围与排期决策见 maps/changelog.md D29，选题优先级见 D32，单包制见 D33③，视觉方案见 D34）

## 目标

从画像页弱项节点一键发起「专项训练包」：按弱项维度组 5 题系列（基础 2 题 → 进阶 2 题 → 挑战 1 题），逐题解锁——完成第 N 题才解锁第 N+1 题；一次只进行一个包（BR-V2-3，画像页其他弱项发起入口显示禁用态并说明原因）；5 题完成后输出包级诊断（有效分轨迹 + 下一阶段建议）；用户可放弃，放弃后已作答题保留评分、包标记 abandoned。

- 首页战役地图式改造（组合原型屏 1，另立任务；本任务只交付训练大厅内的包卡与包详情视图）；
- 包级诊断的 AI 生成（「下一阶段建议」用规则模板产出，不引入 AI 调用）；
- 加练链路行为变更（T21 既有逻辑不动，包会话与加练解耦）。

- **修改 `server/modules/profile/ability-page.ts`**：维度视图增加 `packCta` 状态四态——`available`（可发起）/ `active-self`（本维度包进行中，显示「继续攻坚 n/5」）/ `disabled-other-active`（他包进行中，禁用并附原因）/ `disabled-insufficient`（该维度可组未练题不足 5 道，禁用并附原因）；
- **修改 `app/profile/`**：画像页弱项节点发起入口（落位按 R1 裁定）+ 禁用态说明文案（title/提示，参照屏 6）；

## 失败与回滚

- **迁移回滚**：两表为全新表、不改既有表结构，回滚 = `DROP TABLE pack_items, training_packs`（先 `pg_dump` 备份两表）；无既有数据回填，回滚不影响 V1 闭环；
- **代码回滚**：selection 包层为前置分支，摘除即回退 T29 后行为；画像页入口与大厅包卡为增量 UI，摘除即回滚；服务端全部为新增模块文件；
- **数据保护**：放弃与回滚均不得删除已作答 TrainingSession 与 Score——包会话是普通训练会话，独立成活、照常计入画像与历史；`pack_items.sessionId` 外键 onDelete: SetNull，清包数据时训练数据不受损；
- **冲突处理**：执行中若与 T29 落地后的 sourceType/sourceId 事实冲突，立即停止并在方案层解决，不擅自推进（task/README.md 读取规则 3）。

## 验收条件与完成证据

- 组包正确：同维度 + 难度递进（基础 2 / 进阶 2 / 挑战 1）+ 排除已练；可组未练题不足 5 道时发起被拒并说明原因；
- 解锁严格：第 N 题评分完成才解锁第 N+1 题；接口层无法为未解锁题创建/越权访问会话；
- 单包制：已有 active 包时发起返回 409；画像页其他弱项入口呈禁用态并附原因文案；
- 诊断一致：包级诊断有效分轨迹与 scores 表逐题一致（BR-1/BR-2 系数口径）；建议为规则模板输出；
- 放弃完整：包标记 abandoned、已作答题评分保留、随后可正常发起新包；
- 门禁三件套全绿，新增覆盖率 ≥ 80%；浏览器实证：画像页发起 → 大厅包卡 → 逐题解锁（含评分中过渡态）→ 5 题完成出诊断 → 另发起被禁 → 放弃后可再发起。

## 目标

今日训练流程页从「纵向长滚动页」改为「三栏工作台」：宽屏下整页锁定视口高度，所有信息一屏并存，三栏各自内部滚动；页面本体永不出现纵向滚动条。

## 范围外

资料卡、案例卡、追问区等各卡片内部的视觉重设计（保持现有样式与文案，只做归位）；窄屏（xl 以下）布局创新（维持现有纵向堆叠）；反馈页、历史页等其他页面；任何数据契约与接口改动。

## 交付

1. **三栏结构**（`app/today/training-flow.tsx` 为主，纯布局改动）：
   - 左栏（约 300~340px）：今日案例卡 + 训练重点小卡（现有 `CaseCard` + `FocusCard`，顺序不变）；
   - 中栏（弹性宽）：今日问题卡 + 各阶段交互区（作答 / 追问对话 / 完成态），这是主工作区；
   - 右栏（约 280~300px）：参考资料卡（现有 `MaterialsCard`，从原左栏底部迁入，★核心/○扩展分组、「阅读不扣分」标记、内联原文链接全部原样保留）；
   - 页头（今日训练 + 阶段徽标行）保持在三栏上方，不进入滚动区。
2. **视口锁定**（涉及 `app/today/shell.tsx` 主区与 training-flow 容器）：
   - xl 及以上：主区高度锁定为视口高（h-screen 系），`overflow-hidden`；三栏容器 `min-h-0` + 各栏 `overflow-y-auto` 独立滚动；页面 `<body>` 不出现纵向滚动条；
   - 内部滚动条样式克制（细、低对比，不破坏现有设计语言，可用 Tailwind 任意值或极少量全局 CSS）；
   - 阶段推进（作答 → 追问 → 终答 → 完成）不改变布局骨架，仅中栏内容更新；追问气泡变长时中栏内部滚动。
3. **窄屏降级**：xl 以下完全保持现有纵向堆叠 + 页面级滚动行为（用 `xl:` 响应式前缀切换，不做 JS 断点检测）。
4. **基线页同步**：/baseline 复用 `TrainingFlow`（withShell=false）+ `TodayShell`，布局改动须对基线页同样生效（含基线页自己的进度页头）；基线页同样满足「宽屏页面本体不滚动」。
5. **边界状态不回归**：加载骨架、加载失败重试、无题空态、追问生成失败的降级提示，在锁定布局下仍正常显示（空态/错误态允许居中卡片，不强制三栏）。
6. 全绿：`npm run typecheck && npm run test && npm run lint && npm run build`（纯布局任务，预期无新测试；既有快照/视图测试如因 className 断言受影响，按实现事实最小更新并说明）。
7. **聊天式追问区**（2026-10-07 产品负责人反馈"对话窗口应像大模型 Web UI 一样滚动查看历史，而不是无限延伸；上方保持当前位置，下方与两侧留白平衡"）：

## 封顶失效根因与最终修复（2026-10-07 实证定位）

多轮"纸面正确"的封顶在用户浏览器始终不生效，经浏览器扩展实测定位（evaluate 探针逐层量算）为两层叠加：

1. **Turbopack 缓存陈旧**：`xl:h-screen` 工具类未被生成进 dev CSS（多次强制杀进程导致 .next 缓存损坏）；清除 `.next` 重建后规则恢复；
2. **flex-1 架空 h-screen（真正隐蔽的根因）**：`app/today/shell.tsx` 外壳根节点同时带 `flex-1`（flex: 1 1 0%）与 `xl:h-screen`——flex-basis: 0% 在 Flex 布局中优先于 height，使 h-screen 失效，根节点随内容撑高，全链失守。修复：lockViewport 时追加 `xl:flex-none`（flex-basis 回到 auto，height:100vh 生效）。

实证验收（浏览器扩展在真实页面量算）：文档高=视口高 986px（页面零滚动）；追问卡 4233px→359px 封顶；消息区 clientH 259 < scrollH 4133（内部滚动）；输入卡底边 954px = 训练重点底边 954px（同一水平线）。门禁：665 测试/typecheck/lint 全绿。

## 失败与回滚

- 锁定高度导致某阶段内容被裁切：该栏必须内部滚动兜底，不允许出现看不见的内容；实现后逐阶段（作答/追问/完成/空态）人工走查一遍；
- 回滚点为 training-flow.tsx 与 shell.tsx 两个文件，数据与接口零改动。

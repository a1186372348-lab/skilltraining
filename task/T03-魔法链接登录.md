## 目标

实现免密码邮箱魔法链接登录，身份模型为 users 与 auth_identities 一对多可扩展结构。

## 范围外

账号密码登录、验证码登录、微信扫码（均为 V2，仅预留 provider 枚举）。

## 受影响模块/数据/接口

新增 `server/modules/auth/`、`app/api/auth/*`、登录页；写 `auth_identities`、`magic_link_tokens` 表。

## 可执行步骤

1. 发送接口：输入邮箱 → 生成一次性 token（服务端仅存哈希、15 分钟过期）→ 投递登录链接；开发环境默认输出到控制台，预留 SMTP 环境变量。
2. 核销接口：校验哈希、有效期、未使用 → 建立会话（httpOnly cookie）；token 立即核销。
3. users / auth_identities 分离写入；provider=email_magic_link。
4. 发送接口独立速率限制（防邮件轰炸）；认证端点统一限流。
5. 单元 + 集成测试（过期、重用、错 token、限流）。

## 失败与回滚

token 相关异常一律视为登录失败，不泄露邮箱是否已注册。

## 验收条件与完成证据

- 满足 US-012 全部验收标准与 FR-11
- 完成证据：测试输出摘要 + 一次开发环境完整登录演示记录

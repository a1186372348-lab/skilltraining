## 目标

实现 `content/questions/*.yaml` 的 zod schema 校验与幂等导入脚本，使题目可评审、可回滚、可上架。

## 范围外

题库内容生产（T12）、出题逻辑（T11）、前端页面。

## 受影响模块/数据/接口

新增 `server/modules/content/`、`scripts/import-content.ts`；写入 `questions` 表。

## 可执行步骤

1. 定义题库 zod schema：案例背景、主问题、能力标签 2~4 个（限 8 个一级维度枚举）、难度枚举、Rubric（每维度可观察标准 + forbidden_leaks 禁止泄露点）、提示树恰好 5 层、资料核心 2 + 扩展 3（含标题/来源/原文链接/精编摘要）、status 枚举（draft/published/archived）。
2. 编写校验命令：对目录内全部 YAML 输出逐题校验报告。
3. 编写导入脚本：校验 → 同步至 `questions` 表，幂等（按题 id upsert）。
4. 单元测试覆盖 schema 与导入逻辑（模块覆盖率 ≥80%，先 RED 后 GREEN）。

## 失败与回滚

导入失败整批回滚，不写半截数据；保留错误报告。

## 验收条件与完成证据

- 非法 YAML（标签超界、提示树 ≠5 层、缺 Rubric）被明确拒绝并给出可读错误
- 重复导入不产生重复记录；仅 `status=published` 可被出题读取
- 完成证据：测试输出摘要 + 一次合法样例导入记录

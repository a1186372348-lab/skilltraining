# T25 产品训练模块（IA 重构）

状态：IN_PROGRESS（2026-10-07 立项，决策见 maps/changelog.md D27——4 项关键决策已经产品负责人逐项确认，HTML 原型 prototypes/prototype-training-hub.html 已经产品负责人目验通过并拍板"就按这个方式具体实现"）

## 目标

把分散在「今日训练」「训练历史」「首页」三处的训练链路合并为单一「产品训练」模块：大厅（选题/回看）+ 工作台（做题）+ 只读历史详情三层，形成"做题 → 评分 → 再练一题 → 做题"不离开模块的连续闭环。侧边栏 5 项变 4 项：首页 / 产品训练 / 能力画像 / 我的。

## 范围外

- 工作台三栏布局、历史详情页、评分反馈页的**内容与交互设计变更**（原样迁移，仅改路径归属）；
- 基线测评流程（/baseline 独立入口不变；基线会话不进大厅历史列表，D26⑦/D27 同口径）；
- 能力测评入口、首页仪表盘本身的设计变更（仅更新其指向训练模块的链接）；
- 旧 /history 列表页的任何保留形态（被大厅取代，不共存）。

## 受影响模块/数据/接口

新路由地图（括号内为来源）：

- `/training` —— 训练大厅（新建）：顶部「当前训练」卡三态 + 下方训练历史列表；
- `/training/session/[id]` —— 训练工作台（自 /today 迁移，改为**按会话寻址**：历史列表中"作答中"的旧会话也可点回继续）；若会话 kind=baseline → 重定向 /baseline；
- `/training/feedback/[id]` —— 评分反馈页（自 /today/feedback/[id] 迁移）；
- `/training/history/[id]` —— 历史详情（自 /history/[id] 迁移）；
- 重定向（Next page.tsx server redirect，307）：/today → /training；/history → /training；/history/[id] → /training/history/[id]；/today/feedback/[id] → /training/feedback/[id]；
- 新增 API：GET /api/training/[id] —— 单会话工作台载荷（复用 today 视图构建器，按 sessionId 取；拒绝 baseline kind，复用既有错误码约定；仅限本人会话）；
- 保留 API：GET /api/training/today 作为「今日 daily 会话 get-or-create」供大厅「开始今日训练」按钮使用（拿 sessionId 后前端跳 /training/session/[id]）；POST /api/training/extra 不变（前端拿 sessionId 跳新工作台路由）；GET /api/history 若在大厅落地后无任何调用方则删除（先全局查证引用，含 dashboard）；
- 大厅数据：服务端视图（server/modules/training/ 下新建 hub 视图模块）——
  - 当前训练卡状态机：存在任何非基线未完成会话（status≠scored，取最新）→「进行中」（阶段文案：reading/answering→作答中；followup 未交终答→追问中；已交终答未评分→评分中）；否则今日无 daily 会话 →「未开始」；今日 daily 会话已 scored →「已完成」（附该会话 ≤3 条维度有效得分摘要，「查看结果」跳 /training/feedback/[id]）；
  - 历史列表：非基线会话倒序约 20 条（sessionId、caseTitle、isExtra→「加练」徽章否则「每日」、状态徽章、能力标签、已完成时的维度得分摘要、时间）；分页从简（首版固定条数 + 「加载更多」可留空实现，原型如此）；
- 导航与链接：nav-items.ts 改 4 项；score-notifier 的 feedbackPathFor 与测试、首页仪表盘「今日训练/再练一题」链接、反馈页与完成卡的「再练一题」跳转、history detail 页导航标签——全部指向新路由；
- 文档：Prd.md 3.2 路由蓝图同步为新路由地图；maps/ 相应事实文档如引用旧路由一并更新。

- 状态：IN_PROGRESS
- 背景：产品负责人需要把平台通过公开网络交给面试官使用；本地 docker 数据库与控制台发信不可用，需整体上线。

当前处于发布预检。后台评分调度已接入；当前模型重试最长路径、云端时限、候选构建和仍缺的公网证据见[发布准备复核](../docs/v2/t39-deployment-readiness-20261103.md)。

## 目标与范围

**目标**：将 skilltraining 部署到 Vercel 公网，面试官可通过公开链接注册、魔法链接登录、完成完整训练闭环（作答 → 追问 → 终答 → 后台评分 → 反馈页出结果）。

**已确认选型**（2026-10-22 用户确认）：Neon（云 PostgreSQL，Singapore 区域）+ QQ 邮箱 SMTP（465 隐式 TLS）+ GitHub 自动部署（推 main 自动上线）。

**已确认发布范围**（2026-11-09 负责人确认）：将已验收的完整 V2（含 T27–T33、T37、66 道定稿题）纳入 T39，先准备 Vercel 预览，沿用原线上验收标准。以单独审阅的候选为提交范围，提交、云端变更和真实模型调用按具体步骤另行确认。

**范围外（明确不做）**：

- 自定义域名（先用 Vercel 分配的 `*.vercel.app` 域名）；
- 限流器分布式改造（进程内限流在 Serverless 下降级为单实例粒度，演示场景可接受，记为已知限制）；
- Vercel Cron、对象存储、监控告警等增强；
- 与已验收候选无关的本地改动、缓存、密钥、草稿和未经核验的运行证据。

## 前置依赖（既有事实，已核实）

- 页面全部为客户端壳 + `/api/*` 拉数据，无构建期数据库访问，`next build` 不依赖 DB。
- 后台评分使用 Next.js `after()` 在响应后继续运行，三个评分触发路由声明 300 秒。模型最慢重试路径的预算可超过该时限，需在目标环境验证正常出分和中断恢复。见[发布准备复核](../docs/v2/t39-deployment-readiness-20261103.md#必须保留的时限问题)。
- Vercel 仅封出站 25 端口，465 可用，现有 `SmtpMailer` 零改动复用（<https://vercel.com/kb/guide/serverless-functions-and-smtp>）。
- `PrismaClient` 单例（`server/lib/prisma.ts`）Serverless 兼容；连接串走 `DATABASE_URL` 环境变量。
- GitHub 远程仓库已存在（origin）。

## 受影响模块、数据和接口

1. `server/modules/scoring/trigger.ts`：`TriggerSessionScoringDeps` 增加可选 `schedule`（任务调度器注入）；有 schedule 走 schedule，否则维持 fire-and-forget，inflight 去重与失败重试语义不变。
2. 三个路由经 deps 传入 `next/server` 的 `after`，并显式声明 `maxDuration = 300`：
   - `app/api/training/[id]/final-answer/route.ts`（终答即触发，T36）
   - `app/api/training/baseline/route.ts`（基线状态查询补触发，T36）
   - `app/api/training/[id]/feedback/route.ts`（反馈页懒触发，经 deps 透传至 `server/modules/feedback/view.ts`）
   - 分层约束：仅路由层 import `next/server`，`server/modules/` 不引入 Next 依赖。
3. `package.json`：新增 `postinstall: prisma generate`（Vercel 安装依赖后生成 Prisma Client）。
4. `.env.example`：补生产配置说明（Neon 连接串、QQ SMTP 授权码、AUTH_SECRET、APP_BASE_URL）。
5. 环境变量（Vercel 后台配置，不入库）：DATABASE_URL / DEEPSEEK_API_KEY / DEEPSEEK_BASE_URL / AUTH_SECRET / APP_BASE_URL / SMTP_HOST=smtp.qq.com / SMTP_PORT=465 / SMTP_SECURE=true / SMTP_USER / SMTP_PASS / SMTP_FROM。

## 失败、回滚和数据保护

- Vercel 一键回滚上一部署；Neon 数据独立于部署不受影响。
- 本地开发环境（docker PG + `.env`）完全不受影响，环境差异全部走环境变量。
- 反馈页与基线状态可补触发评分。中断恢复和跨实例重复调用须按发布门禁验证。回退前确认旧评分写入已隔离、数据保留和写入兼容性。
- 密钥一律在 Vercel 环境变量配置，不进 Git、不进文档。

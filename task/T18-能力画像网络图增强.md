## 目标

让 3D 网络图一眼可读：节点名称与分数常态化显示，色彩直观区分短板与优点；节点弹窗的「评估依据」从长篇诊断原文改为可跳转的最近评估记录列表。

## 范围外

二级维度节点；评估记录分页/筛选（固定最近 6 条）；反馈页本体改动。

## 交付

1. **常态化标签**：react-force-graph-3d `nodeThreeObject` + three-spritetext，在节点旁常驻渲染维度名与分数（未观测显示"未观测"）；标签随节点缩放保持可读，深色背景上对比度足够。
2. **色彩语义**（`app/profile/network-model.ts` 纯函数调整 + 测试更新）：低分节点暖色警示（琥珀/橙系），高分实蓝，未观测灰态；连线粗细动态范围加宽，优劣一眼可辨。具体分档阈值与色值由实现者按既有蓝系设计语言定，保持克制。
3. **评估记录契约**（TDD 先行）：
   - `server/modules/profile/ability-page.ts`：每维度 `latestDiagnosis` 字段移除，新增 `recentEvaluations: [{ sessionId, score, scoredAt, caseTitle }]`（该维度最近评分记录，时间倒序，上限 6 条；score = 该维度 effectiveScore，caseTitle 取关联题目案例标题）；
   - `app/profile/contract.ts` 同步；`recentScores`/`sparkline` 趋势数据保持不变；
   - 注意 dashboard 模块的 `latestDiagnosis` 是独立契约（server/modules/dashboard），不受影响，不要动。
4. **弹窗改造**（`app/profile/node-detail-modal.tsx`）：「评估依据」区段改为「最近评估记录」列表——每条一行：评分日期 + 有效分 + 案例标题（一句话简介，超长截断）+「查看评估 →」按钮（`next/link` 跳转 `/today/feedback/[sessionId]`）；观察趋势、提示依赖、下一步方向三个区段保持不变；未观测维度保持现有空态。
5. **固定大小重设计**（2026-10-05 产品负责人反馈"动态适配时机不稳、忽远忽近，不要补丁式修改，重设为固定大小"）：**废弃 zoomToFit/onEngineTick/onEngineStop/warmupTicks 全部动态适配机制**，改为确定性呈现——
   - 布局确定：8 节点按固定环形坐标排布（network-model 纯函数产出 fx/fy/fz 钉住位置，z 轴小幅交错制造纵深），不再依赖力导向模拟的随机结果；
   - 镜头固定：挂载时一次性设置固定相机位（cameraPosition，距离按目标观感调定：整个网络含标签约占容器高度的 55~65%，居中，全部标签完整可见，参照目标截图 `C:\Users\yang\Desktop\ScreenShot_2026-10-05_210651_638.png`）；
   - 防闪烁：相机未设置前容器透明，设置完成后显示，任何时刻用户都不会看到错误大小；
   - 交互保留：背景拖动旋转、滚轮缩放、点击节点开弹窗；节点本体拖动禁用（enableNodeDrag=false），消除"拖节点重燃引擎重置视角"一类副作用。
6. **渐变连线 + 图例**（2026-10-05 产品负责人提供 GPT 设计参考图 `C:\Users\yang\Desktop\能力画像：3D能力网络图.png`，取代 D20「短板定粗」规则）：
   - 连线改为锥形渐变粗细（linkThreeObject 自定义锥/柱体）：每条边在分数高的一端粗、分数低的一端细，两端半径各由该端节点分数决定；未观测一端取最细并保持淡灰虚态；半径规则收敛在 network-model 纯函数并 vitest 覆盖；
   - 图区右上角新增固定图例（HTML 覆盖层）：已评估·较强（实蓝）/ 已评估·一般（淡蓝）/ 已评估·较弱（琥珀）/ 未观测（灰）四档圆点；
   - 背景沿用深色知识空间，可参照参考图叠加克制的径向光晕/星点层次（纯 CSS，不新增依赖）；
   - 节点布局维持交付项 5 的等间距圆环（参考图布局较乱，产品负责人明确"8 节点全部环绕外环、相同间距组成一个圈"）。
7. 全绿：`npm run typecheck && npm run test && npm run lint && npm run build`。

## 失败与回滚

three-spritetext 加载失败走既有 ErrorBoundary 降级为列表视图；契约改动仅限 profile ability API，dashboard/历史/反馈页不受影响。

## 验收条件与完成证据

- `/profile` 3D 图无需悬浮即可看到每个节点的维度名与分数；低分节点暖色、高分实蓝、未观测灰态
- 点击节点弹窗显示最近评估记录列表（时间+分数+案例标题+跳转按钮），点击跳转对应训练反馈页且页面正常打开
- 无评估记录的维度弹窗显示空态文案，不报错
- 质量门禁四项全绿

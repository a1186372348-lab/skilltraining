# 计划方案（docs/）

> 文档类型：计划方案与设计文档入口
> 负责范围：尚未成为当前实现事实的文档——初版方案、计划方案、技术评审、调研、决策前材料、交接
> 更新触发：新方案立项、方案状态变化、方案被实施或废弃

## 目录职责

| 目录 | 负责内容 | 不负责内容 |
|---|---|---|
| `docs/` | 计划方案、评审、调研、交接和临时设计材料 | 当前实现的事实、可执行任务正文 |
| `maps/` | 已实现并验证的当前事实 | 未实现的目标方案 |
| `task/` | 可执行任务与验收证据 | 未来方案全文 |

## 内容准入

允许：

- 未实现或部分实现的目标方案及从属规范
- 方案比较、调研、评审和决策前材料
- 阶段交接、复审状态和临时证据
- 用于沟通的文档产物

禁止：

- 当前代码、API、数据库或页面的长期事实地图（进入 `maps/`）
- 具体可执行任务正文（进入 `task/`）
- 真实用户数据、图片内容、数据库内容或密钥
- 可执行源码（辅助脚本放入 `scripts/`）

## 状态约定与生命周期

1. 方案文档必须明确状态：草案、待确认、已确认、已废弃或历史材料。
2. 方案实施后，把代码已经验证的当前事实提炼到对应 `maps/` 文档，不复制整份方案。
3. 已完成任务的执行证据保留在 `task/` 或交接材料中，不追加到长期事实地图。
4. 不直接删除临时文档；优先标记状态或移入明确的归档目录。

## 读取规则

大型方案默认渐进读取：先搜索目标、模块、章节标题或决策关键词，再读取命中章节。
只有全文复审、文档维护或用户明确要求时才完整读取。
